Hyeto may be studied, modified and redistributed only for noncommercial purposes under the PolyForm Noncommercial License 1.0.0. Hyeto is itself a derivative of Rainform / 数据成雨 by afterimage, so the upstream terms apply to Hyeto and to everything built on it.

## Recommended process

1. Describe the product, platform, distribution model and funding model before integration.
2. Work from this source repository, not the minified production bundle.
3. Keep Hyeto-derived files in a clearly named module or directory.
4. Preserve `LICENSE`, `NOTICE.md` and every `Required Notice:` line — including the upstream Rainform notice.
5. Add visible attribution in the host project's README and About/Credits interface.
6. Use a clearly different name and visual identity; do not present the result as an official Hyeto or Rainform release.

Recommended attribution:

```text
Rain visualization derived from Rainform / 数据成雨 by afterimage
https://rainform.pages.dev/
via Hyeto — https://github.com/JavaLyHn/Hyeto
```

## License compatibility

PolyForm Noncommercial adds a noncommercial restriction. It is not an OSI-approved open-source license and should not be merged into another project's files while claiming that the entire combined repository is covered only by MIT, Apache, GPL or another standard open-source license.

Keep Hyeto-derived material separately identified with its own license and notice. If the host license requires the entire combined program to use one license, obtain written project-specific permission before copying code. Attribution alone does not resolve license incompatibility.

Hyeto cannot grant permissions broader than the ones it received. Any exception to the noncommercial restriction, and any relicensing, must come from afterimage as the upstream licensor.
