# Integration policy

Rainform may be studied, modified and redistributed only for noncommercial purposes under the PolyForm Noncommercial License 1.0.0.

## Recommended process

1. Describe the product, platform, distribution model and funding model before integration.
2. Work from this source repository, not the minified production bundle.
3. Keep Rainform-derived files in a clearly named module or directory.
4. Preserve `LICENSE`, `NOTICE.md` and every `Required Notice:` line.
5. Add visible attribution in the host project's README and About/Credits interface.
6. Share a preview with the maintainer before presenting the integration as a collaboration.

Recommended attribution:

```text
Rain visualization derived from Rainform / 数据成雨 by afterimage
https://rainform.pages.dev/
```

## License compatibility

PolyForm Noncommercial adds a noncommercial restriction. It is not an OSI-approved open-source license and should not be merged into another project's files while claiming that the entire combined repository is covered only by MIT, Apache, GPL or another standard open-source license.

Keep Rainform-derived material separately identified with its own license and notice. If the host license requires the entire combined program to use one license, obtain written project-specific permission before copying code. Attribution alone does not resolve license incompatibility.

## Scope

Permission to integrate code does not grant permission to reuse Rainform's name, icon or official social artwork as another product's identity. It also does not authorize commercial distribution, sublicensing or reuse in unrelated projects.
